# Android 连接优化（0.14.13）

Android 小米 SPP 默认复用已有系统配对；未配对时先发起系统配对，完成后优先连接标准安全 SPP UUID。标准连接失败后才尝试兼容方式，保留手动重建配对选项。自定义蓝牙服务仍保留自己的连接顺序。

手机设备卡片显示准备、配对、串口、兼容连接、等待重试、协议协商和 Key 验证阶段。进度按设备地址与本次连接任务过滤，旧任务的事件不会覆盖新设备状态。

用户取消/拒绝配对、配对超时、权限不足、蓝牙关闭不自动重试；链路临时失败使用有上限的退避和随机延迟。Android 默认启用有上限的断线自动恢复，已保存的用户选择仍保留；最多尝试三轮，主动取消或切换设备会终止等待中的恢复任务。可以在“蓝牙连接方式”页面关闭自动恢复。

连接鉴权和云端安装授权流程继续独立执行，只有设备确认鉴权成功才能安装。安装权限不因兼容连接方式变化而放宽。

验证包括连接状态按设备过滤、配对拒绝停止重试、等待重试期间取消、错误分类与退避上限、现有连接/配对设置回归，以及 Android release 编译。真实手机与手环的系统配对确认、断线恢复、安装仍需实机验证。
