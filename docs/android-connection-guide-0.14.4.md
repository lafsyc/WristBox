# Android 0.14.4 连接教程与自动读取

首页原“应用工坊”入口暂时替换为“连接教程”，商店中的“创意工坊”分类保留。教程提供小米账号同步、本地日志读取、默认直接连接、手环连接新设备、兼容配对设置和手动 Key 的说明与入口。

日志自动读取只查找明确授权的 wearablelog / ResearchLog 文件夹。首次授权后可以直接读取最新日志；从日志页面打开运动健康、导出并返回时，只查找本次打开之后的新日志。没有新日志时提示重试，不静默导入历史记录。用户此前已有所有文件访问权限时，也可按需查找 Download 中的上述两个目录，本功能不申请此权限。

自动读取不等于自动修改设备凭据：解析后仍需确认目标设备，保存后可验证连接。小米账号同步及单文件选择继续保留。日志不上传、不解压落盘；授权可在页面撤销。运动健康仍需要由用户触发日志导出，不能保证所有版本都输出 Key。

版本：0.14.4+33；隐私说明版本：2026-11-06.3。没有服务端部署或线上版本发布操作。

验证覆盖：15 项 Flutter 测试（页面导航、小屏/主题、日志解析、目标设备核对、自动读取权限不足和返回应用生命周期），原生目录定位测试（最新文件、时间过滤、目录范围、空文件、轮转日志与扫描数量上限），新增 Dart 文件静态分析。原生代码随 Android release 构建验证。真机仍需验证各厂商文件夹授权、运动健康日志导出和手环连接。
