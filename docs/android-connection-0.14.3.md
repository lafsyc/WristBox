# Android 0.14.3 连接兼容性

默认保留已有系统配对，直接尝试 RFCOMM 连接，由 Android 按需展示系统配对提示。原来的主动移除配对并等待重新配对流程保留在「我的 → 蓝牙连接方式 → 连接前重建系统配对」中，默认关闭，启用前提示对运动健康及解锁手机配置的可能影响。仅作用于下一次连接，不修改 Windows 连接设置。

等待系统配对时，单个 socket 获得从连接开始计算、不可反复延长的 45 秒窗口。手环认证等待增加到 45 秒。Android 不再叠加外层两次重试；管理器已有的传输重试仍保留，外层总超时为 240 秒，避免原来的 55 秒超时打断确认。

保留 Key 的双向认证和系统配对确认，不自动接受确认，不意味着运动健康和 WristBox 可同时操作设备，也不能保证所有固件均可绕过手动进入连接模式。

参考：AstroBox-NG-Plugin-BtClassicSpp/android/src/main/java/BTSpp.kt 的连接流程直接尝试 SDP/RFCOMM；OronBox MainActivity 的流程会先 ensureBonded。未替换完整传输实现，仅调整本项目的默认配对策略与等待窗口。
